## 1. The window correction: 1–4 s DILUTES dv/v ~50× → use 2–4 s  (06-07)
- **1–4 s window flattens dv/v ~50× toward zero.** Mechanism (airtight): the alignment-pinned direct-S is
  **98% of the 1–4 s window energy**; the stretch is a correlation, so the motionless S drags the fit to ε≈0.
  Regression `dvv(1-4) = 0.018·dvv(2-4)` → 1–4 s keeps only **2%** of the real coda signal. Energy fraction (2%)
  = retention (2%), self-consistent. (B927 c660: 1–4 std 0.016% vs 2–4 std 0.173%.)
- **Correct band = 2–4 s**: off the pinned S (S at ~0.97 s), inside the coherence floor (~4 s; 3–5/4–6 decorrelate
  even with max stacking+SVD — a coherence statement, not amplitude).
- **Method:** per family, 30-day **causal trailing** rolling WAVEFORM stack + SVD-Wiener + stretch 2–4 s.
  **NEVER median dv/v over time** (the stacking IS the smoothing). Cross-family median is OK (per-day SPATIAL).
- Rolled out to all 28 stations. ETS null **confirmed in 2–4 s** (robust ≥4-sta network std 0.019%, tremor corr ~0.05)
  — so the 1–4 s dilution was NOT hiding an ETS signal; the deep fault is genuinely velocity-stable.
- Full-GNW (1995+) 2–4 s shows **no Nisqually-2001 precursor** → strengthens the response-removal-artifact verdict.

## 3. Multi-window joint inversion (06-08/09)  — `fault_tomography/inversion/invert_multiwin.py`
- One **shared deep fault field** m_f; each window (1-3/2-4/3-5) has its OWN single-scatter kernel (different
  ellipsoid → depth leverage) AND its OWN **per-station site term** (later coda = more surface). Stack all
  (cell,station,window,month) rows, joint LSQR per month. Fault = across-window common mode; site = window-specific.
- **Checkerboard 0.88** (up from 0.77 single-window) — the depth leverage is real. VR 42% (deseasoned) / 45% (raw),
  196 resolved cells (≥3 sta), robust temporal RMS 0.045%, network fault index −0.39…+0.04% (flat when robust).
- `DESEASON=0/1` env → `fault_4d_multiwin{_raw}.npz` (now also saves `SITE` site terms + labels).

## 5. NEAR-SURFACE vs FAULT separation (the key insight, 06-09)
- The **site terms ARE the near-surface (shallow-crust) change** — one inversion yields TWO products:
  deep fault field (m_f) + near-surface field (site terms). Physically separated by geometry (deep = common
  across windows/stations; shallow = per-station).
- **The seasonal lives in the near-surface**, not the fault: raw-inversion site terms show big annual cycles
  (B036 **0.32%**, GNW 0.009%); the **fault index is ~identical raw vs deseasoned** → seasonal does NOT leak to
  the fault. This also CLOSES the raw-vs-deseasoned question: deseasoning wasn't eating real fault signal.
- Near-surface footprint ≈ **nominal ~25 km disk** (fuzzy 10–40 km, strongest under station; seasonal = top few km).
  Site terms are LUMPED per station (no resolution between stations without a shallow-layer + receiver-lobe kernel).

## LESSONS
- **Calendar > count-based rolling** for gappy stations (count-based stitches across gaps).
- **Multi-window joint inversion adds real resolution** (0.77→0.88): fault is the across-window common mode.
- **Site terms = the near-surface field** — don't discard them; they're the second product (and where seasonal goes).
- **SVD-Wiener is not causal** (uses whole-record basis) AND can **smear/shrink a sharp coseismic drop** (treats a
  localized transient as noise). Use `--no-svd` (raw rolling) for strict causality / earthquake-timing work — PARKED.
- **Continuous-fill renders MISLEAD**: interpolation makes sparse-south noise look like confident signal — always
  overlay data-vs-interpolated, and read coverage (station density) alongside.
