Keep a running log AS I WORK — progress, decisions, and lessons learned — not only when
explicitly asked. Append to a dated daily note `notes/YYYY-MM-DD_Notes.md` (and update the
authoritative runbook / resume docs when a reusable lesson emerges).

**Why:** sessions crash often and context is lost; the user values a durable trail of what
was done, what was found, and what was learned (e.g. station QC verdicts, instrument-artifact
findings, parameter choices). It also serves the "hundreds of stations" goal — each station's
result + gotchas should be recorded as they happen.

**How to apply:** after each meaningful step (a station processed, a QC finding, a bug fixed,
a parameter decided), jot a few lines to the daily note: what I did, the key numbers/outcome,
and any lesson. Don't wait for a "write notes" request. Link reusable lessons into
[[gpu-family-discovery]], [[pnsn-catalog-cut]], and the METHODS/RESUME runbooks.
