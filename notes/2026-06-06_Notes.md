### Methodology refinements this batch
- **Family selection = coverage-balanced + top-10% highest-SNR added back** (user: keep the strongest
  repeaters; don't let coverage-balance drop them). Select UPFRONT before densify (don't re-densify to add).
  See memory [[family-selection-rule]].
- **min-det is station-dependent:** rich central boreholes keep min-det 20; distant/sparse eastern/southern
  ones (B204, B028) use min-det 8 or they're starved.
- **dv/v y-limits auto-scaled** to each station's amplitude (not fixed ±0.05).
- **plot_family_map.py fix:** only draw reference stations within the station's own extent (was stretching
  southern maps tall to reach far-north labels via bbox_inches='tight').
