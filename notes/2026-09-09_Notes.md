# 2026-09-09 — SSE model: space-time connected slip patches > 5 mm / 30 d (user request)

Script fault_tomography/inversion/sse_slip_patches.py (env THR mm, SIGN=-1 for the mirror/back-slip catalog).
Field: thrust slip accumulated within (t-30, t] on the model's own 742-triangle mesh (0.25°, fallback Slab2 geometry),
daily 2007-2026, from A_raw x Ld (sign as sse_trailing_products.py). Linking: same-day vertex-sharing triangles +
same triangle on consecutive days -> connected components = temporally inter-connected slip patches.
Outputs: res_catalog_sse/slip_patches_5mm.{csv,npz} (labels T x 742), figures/sse_slip_patches_5mm.png; mirror
catalog slip_patches_5mm_mirror.* (back-slip < -5 mm).

Results (thrust): 118,778 patch-days above threshold -> 2196 components; 332 non-minor (>=3 triangles & >=30
patch-days, 91 % of patch-days); 203 with Mw>=6.0, 17 with Mw>=6.5 (mu 30 GPa, cumulative slip on the footprint over
the active span). 48 "broad pulses" (<14 d yet >300 km along strike, e.g. 2012-01-15, 2014-10-09, 2017-04-09,
2021-03-12, 2023-02-10: whole southern segment lit for ~11 d) — suspect vbICA/GNSS common-mode blips, flagged.
Northern ETS components are clean, ~14-month recurrence, 30-85 d, 12-49 kkm², peak 17-30 mm/30 d, Mw 6.3-6.8; the
largest: 2015-12-28..2016-03-21 (43.7-49.4N chained, Mw 6.79), 2007-02 (6.68), 2017-02..05 (6.63), 2011-01 (6.61),
2010-08..10 (6.58), 2020-10..11 (6.58), 2024-08..10 (6.58), 2011-07..09 (6.57), 2013-09..11 (6.55), 2008-05 (6.49).
Migration fits mostly +2..+4 km/d (northward) for the northern events, negative for some southern ones.

NOISE FLOOR (mirror): back-slip < -5 mm gives 69,573 patch-days / 2737 components. Per segment (thrust vs mirror
patch-days): S 40-44N 44.7k vs 37.3k (ratio 1.2), C 44-46N 9.5k vs 10.1k (0.9), N 46-50N 64.6k vs 22.2k (2.9).
Cell-level: south p5/p95 of the 30-d increment = -5/+5 mm (symmetric), north -4.3/+6.2 (asymmetric). So at 5 mm/30 d
the southern and central catalogs are AT the model's oscillation floor (as many back-slip patches as thrust patches, same
Mw range); only the northern segment (and thrust peaks > ~15 mm/30 d anywhere: 35 components vs 0 mirror) is above it.
Largest mirror components are margin-wide (e.g. 2021-12-24..2022-01-28, 39.8-49.7N, 132 kkm²) -> reference-frame /
common-mode artifacts in the GNSS solution, same class as the broad pulses.

patch_response_heterogeneity.csv; figs figures/sse_patch_prepost.png, sse_patch_prepost_model.png, sse_patch_response.png.

RESULTS (interface, Mw>=6.2, n=34: 17 N / 4 C / 13 S):

- CENTRAL (4): all DUR-PRE negative (-0.53, -0.02, -0.33, -0.49), none significant, overdispersion 0.35.

  floor and both sit in the 2013-2015 window where dv/v station glitches are known (PGC 2013-14) -> suspect, not a response.

- Family 2-4 s: nothing (|Δ| <= 0.03 %, all p > 0.08).

MODEL CHANGES INSIDE THE PATCH (north, Mw>=6.2, footprint means 10 km above the interface): slip in window +6 mm/30 d (by
construction), cumulative slip +3.0 mm DUR / +5.4 mm POST vs PRE; shear stress (receiver strike 0/dip 12/rake 90) -0.12 kPa DUR /
