## Backward extension (before 2018)

Question: can the 27 families be followed back before 2018 with the stations that existed then?
A station counts for a period only if it ran the same sensor model then as during the 2018-2024 template build. Gain-only changes do not affect a normalised cc; other stations are dropped.

**Plain summary.** Only 6 of the 17 S1 stations were running before 2018: NC.KMPB (CMG-3ESPC since 2008-04-29), NC.KMR (STS-2 since 2007-01-30) and PB.B049/B932/B933/B934 (borehole HS-1, installed Sep-Nov 2008). We re-ran the detector with only these stations on the same held-out 2018-2024 days used for the v3b score. 17 stations (v3b): any-family recall 0.68, precision 0.78; S6 (pre-2018 stations): any-family recall 0.31, precision 0.85; S2 (KMPB+KMR): any-family recall 0.03, precision 0.98 (9×MAD, Text S1 rules). PASS: BK1 S6 at 9xMAD (S1 rules, source mode) any-family precision 0.855, recall 0.309; rule: BK2 runs only if precision >= 0.5
