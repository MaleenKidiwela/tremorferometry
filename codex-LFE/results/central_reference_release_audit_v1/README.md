# Public-reference release follow-up

This audit extends the earlier regional benchmark inventory; it does not repeat waveform or picker tests.

The current CRESCENT catalog-directory listing was downloaded through GitHub's API. Its additional 2022–2026 entries inspected here describe ordinary tectonic, offshore, or volcanic earthquakes, rather than the missing Oregon/Olympic LFE event tables. Do not use them as LFE positives. The directory listing and six source metadata pages are retained locally.

Primary sources checked:

- Chestler and Creager (2017), https://agupubs.onlinelibrary.wiley.com/doi/full/10.1002/2016JB013717 : the acknowledgment identifies archived AofA/CAFE waveforms, and the page lists one supplementary PDF. No machine-readable event catalog link was identified in the inspected page.
- Sweet et al. (2019), https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2018GC007998 : the acknowledgment identifies XU/XG waveform archives, and the page lists a supplementary Word document. No event-table download was identified in the inspected page.
- Thomas and Bostock (2015), https://pages.uoregon.edu/amthomas/pubs/thomas_tectonophysics_2015.pdf : remains an established central-Oregon benchmark; this follow-up did not locate its machine-readable event times.
- https://www-solid.eps.s.u-tokyo.ac.jp/~sloweq/ : browser request timed out; this is an access failure, not evidence that catalogs are absent.
- https://github.com/cascadiaquakes/earthquake_catalog_repository : source of the locally saved metadata pages.

No authors were contacted. Public reference acquisition remains incomplete; these findings do not establish that no public release exists.

## Roster check for the Oregon benchmark

The three discovery stations named in Thomas and Bostock (2015), ALP0, ALS0 and BWO0, are absent from the exact user roster. Of the station labels in the paper's Figure 1, only PB.B031 and PB.B032 occur in that roster. The paper describes these two as later stacking checks, not stations in the scanning template. Thus a strict-roster run cannot be called a replication of the original Oregon discovery array. Modern roster stations near the same source region offer a different, denser network; they need their own validation. No station aliases or out-of-roster stations were added.
