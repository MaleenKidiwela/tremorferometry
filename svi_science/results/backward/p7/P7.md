### Common definitions (pinned)
- P = the P6 headline `P_same` of the candidate's model (P6.md). All candidates ≥ 8 MAD; no T anywhere except the
  headline counts.
- Observable family-days m = `observable` rows of the `_fd` files of the same series (data or control).
- Day classes (`p4/envflag/tables/quiet_flag_env.csv`): **env-quiet** = `quiet_env3_CN4` (the pre-2010 quiet flag, used in
  every year so the definition never changes); **between** = > 3 d from every Bostock window; **ETS** = inside a window;
  **PNSN-quiet** = forward Track C rule (2010-01-10 on).
- Primary detector: era for 2003-02-01 → 2006-06-30 (PLAN decision), frozen otherwise.

### Item 5 — completeness ladder and overlap k
- `bw_p4b_kladder.py --p-dir svi_science/results/backward/p6/P` unchanged (P = P6 headline). Outputs land where the script
  writes them (`p4b/tables/k_ladder.csv`, `k_ladder_agreement.csv`); P7 copies them to `p7/tables/` and summarises.
- Primary k = day class env_quiet, rows all. If that k is not finite or ≤ 0, fall back to `between`, then `all`
  (fallback recorded). Agreement: env_quiet / between / ets / all within ×2 → "agree", else the bracket [min, max] of
  the finite positive values is carried.
- **Chain to the S15 (B4) level**, K_set = factor that turns a set's excess into S15-equivalent excess:
  K_B4 = 1; K_B3 = k(S15/B3); K_B2 = K_B3 · k(B3/B2); K_B1 = K_B2 · k(B2/B1); K_B0 = K_B1 · k(B1/CN4).
  Era: K_era = K_set / k(era/set) via each overlap (CN4, B1, B2); **primary via B2** (fewest chain links); the three
  agree within ×2 → "agree", else bracket. Uncertainty: per link σ_ln = (ln k_hi68 − ln k_lo68)/2, added in quadrature
  along the chain (log-normal); 68 % and 95 % intervals reported.

### Item 6 — rate tables (forward format)
- Per (family, UTC date, detector), the columns of `lfe_extension/results/refine/rates/famday.parquet`: `n_data, n_c1,
  sumP_data, sumP_c1, varB_data, n_core_data, n_core_c1, foldsd_sum_data, sset, n_sta_day, k, k_lo, k_hi, excess,
  rate, rate_sd, quiet, bracket_lo, bracket_hi, month, v11_cat_core, v11_cat_ext, inter_ets_mode` with the forward
  meanings: excess = ΣP_data − ΣP_control; k = his/ΣP per (family, set), shrunk as `svi_ref_rates.shrink`; rate =
  excess × k; rate_sd = √(Σp(1−p) + foldsd²) × k; bracket on quiet days = [excess × k_lo, n_core_data − n_core_c1];
  v11 columns = 0 (no v1.1 before 2014).
  - k per (family, set): B3 = forward S14 row, B4 = forward S15 row of `refine/rates/k_factors.csv` (unchanged);
    B0/B1/B2 = the same shrink code on the P6 out-of-fold P of the G1 fit rows (2011 + 2012 test blocks); era = the
    same code on the era model's out-of-fold P of the 2004 build blocks (caveat: template events).
  - n_core at T_core of the set (B2/B3/B4 8.75, era 8.25); CN4/B1 at both bracket ends (`n_core_*` at the MED end
    8.79 / 8.69, `n_core_*_Thi` at 9.82 / 9.56).
- **Uncorrected vs k-corrected:** `excess`, `rate` = uncorrected (the set's own sensitivity; `rate` uses the forward
  Bostock k of the set); `excess_kc = excess × K_set` and `rate_kc = excess_kc × k(family, S15)` = completeness-ladder
  corrected to the S15/B4 level, with `K_set`, `K_lo95`, `K_hi95`. Extra columns: `detector`, `primary`, `era`,
  `net_set`, `m_data`, `m_c1` (observable family-days: 1 or 0 per row), `quiet_env3_CN4`, `quiet_pnsn`, `burst_day`,
  `excess_ms` (n_z2 ≥ 2 rows only), `ets`, `between`.
- Every (family, date) with an observable data family-day gets a row (zeros allowed), so rates can be divided by
  family-days. Monthly tables `monthly_family` / `monthly_total` as forward, plus the same with `_kc`.
- `inter_ets_mode` per era from G6 below.

### Item 7 — step checks
- **(a)** P4-2b steps 1–2 as computed (`p4b/tables/p4b_e0_decision.json`, `p4b_era_decision.json`): reported pass/fail.
- **(b)** at every boundary: set boundaries 2005-07-01, 2005-11-02, 2007-11-13, 2009-08-27; detector switch 2006-07-01
  (era → frozen B2); backward → forward junction 2014-01-01 (B4 production `p5f_2013` → forward `refine/rates/famday`
  S15/S14 production; network daily excess per day, as no observable family-day count is stored forward); instrument
  changes SNB 2006-04-20, NLLB 2007-01-27, VGZ 2007-02-28, SNB 2008-12-11, VGZ 2009-07-31, SNB 2011-03-17 (frozen);
  KELB gain 2003-07-31, KELB → KLNB 2004-06-04 and the POLARIS/C8 losses KHVB 2004-08-05, SHVB 2004-09-30, SHDB
  2005-01-11, TWGB 2005-05-10, MGCB 2006-05-13, TWKB 2006-05-14, SSIB 2006-06-16, TSJB 2006-06-19 (era). Statistic:
  network excess_kc (k-corrected) per observable family-day on **between** days and on **env-quiet** days, 60 d after
  vs 60 d before; z = ln(after/before) / σ, σ from a 2000-draw day bootstrap within each side. **Flag |z| > 2.**
  Undefined when a side's excess ≤ 0 (reported). Same with excess (uncorrected) beside. **(b) passes** if no set
  boundary, no detector switch and not the junction is flagged on between days after k.
- **(c) control fairness**: per detector × set, over env-quiet days, OLS slope of the daily excess per family-day on the
  daily control ΣP per family-day, 2000-draw day bootstrap 95 % CI; all rows and n_z2 ≥ 2 rows. **Pass = CI contains
  0**; |slope| ≤ 0.25 reported as "small".
- **(d)** recall vs ladder k, within ×1.5:
  - d1 (same days, same truth): recall_era / recall_frozen at P ≥ 0.75 on the P6 look windows (2003, 2005-09; 2004
    test blocks reported as seen) vs the overlap k (era/set) of the ETS day class. Pass if the two ratios are within
    ×1.5 of each other.
  - d2 (chain): recall(set, its look window) / recall(S15 reference at P ≥ 0.75 on the forward 2011 + 2012 test-block
    out-of-fold rows, `refine/conf/candidates_conf.parquet`) vs 1 / K_set. Within ×1.5 → pass. Different episodes and
    catalogue densities: read with care.
- **(e)** 2010–13 between rates on env-quiet days (env-flag N below its k = 12 threshold): B4 excess per family-day on
  env-quiet days vs on PNSN-quiet days, per year and pooled. Agree if the pooled ratio is within 0.8–1.2 (the forward
  invariance bar). This is the bridge between the pre-2010 and post-2010 quiet definitions.

### Original P7 controls (per era = detector × set)
- **Scrambled-control ΣP:** ΣP_control / ΣP_data per detector × set × year, all days and between days, against the
  forward 0.34–0.50; forward bar (≤ 0.05 per epoch and |Spearman of the monthly control ΣP per day vs time| < 0.3) applied.
- **Withheld S-energy** (forward `svi_ref_val` check 1, same code logic): on quiet days (env-quiet before 2010-01-10,
  PNSN-quiet from then), `conf_ze` (S-energy of the 2 lowest-weight sites, in no model) of data with P ≥ 0.5 minus all
  control rows; pass = day-bootstrap 95 % CI > 0 AND Spearman of data `conf_ze` over the P bins (n ≥ 30) > 0.
- **Station-set invariance** (forward `svi_ref_val` check 3 logic): the P4-2 runs on the 509 E0 PNSN-quiet days
  (`p4/mf/feat/p4e0_{CN4,B1,B2,B3,S15fix}`): k_set · ΣP_data(set) vs k_S15 · ΣP_data(S15fix), pooled and median monthly
  ratio, bar 0.8–1.2 (k_set = pooled his/ΣP of the set on its fit days); the ΣP-excess version and the direct quiet-day
  k = excess(set) / excess(S15fix) beside (compared with the ladder chain K, ×2).
- **G6 per era:** "rate" only if withheld S-energy AND control ΣP AND invariance pass for that set; else
  "control_subtracted_bracket" (the forward outcome).
