# MERLIN — audit of S15 Q1/Q2 (2026-10-17; saved by the main session)

**Model check**: Fable 5.1 (claude-fable-5-1), not downgraded.

**Verdict**: Both tests are sound and their controls are the right ones; Q1 and Q2 stand. The one thing to change before the findings page is the mechanism clause: the data say "late in the local sequence and more tide-sensitive than the LFEs around them", but they cut against the simplest reading of "large swings of a tidally modulated slip rate" (see 4). All checks below are read-only recomputations from `svi_science/results/s15_vlfe_science/tables/` (q1_events.csv, q1b_pseudo_anchor_lfe.parquet, q2_events.csv).

1. **(a) Q1 control is right; rate conditioning does not move it.** No LFE criterion enters the 540: ETS label is time-window only (`cat_common.period_of`), `battery_e2` = pass_a,b,c,e2,f (cat_common.py 122–147), `lfe_status` is a column. VLFEs sit in *less* dense LFE surroundings than the eligible pseudo-VLFEs (±10 min count median 5 vs 6, mean 5.9 vs 8.4), and pseudo-VLFE Δt rises only weakly with that count (ρ 0.15). Re-anchored control stratified on the count (1 / 2–3 / 4–6 / 7–12 / 13+): median 1.22 d (p99 1.40) vs 1.17 unstratified; drawing with probability ∝ count: 1.26 (p99 1.45); VLFE median 1.79 above all draws, and VLFEs are 0.6–1.3 d later within every stratum. SVI-only anchor (WA-NW families carry 20 % of the weight; 44 % of VLFEs have some): 1.77 vs 1.18 d (p99 1.36). MINOR, report as a column: the 73 single-family events (q1b_day_per_direction.csv) are late only SE-ward (+1.2 d, n 13–14); NW-ward +0.05–0.08 d, pct 60–66 (n 52–59). Δt vs Mw_scan ρ 0.07 (no size dependence).

2. **(b) Q2 control is right and conservative.** Reconstructing the ±24 h matched draws (VLFE phase + linear M2 advance) reproduces a 0.47, −43°. Weighting the LFE draws by burst intensity *lowers* the LFE modulation: ∝count 0.43, ∝count² 0.40, top-quartile bursts only 0.38. Excluding the VLFE's own hour (±1 h) drops the LFE value to 0.27 (S5 whole-catalogue 0.35), so the 0.47 control is itself inflated by the VLFE-hour LFEs; the honest LFE baseline is 0.27–0.35. Clustering: 155 singletons, clusters up to 28 in one hour; z = 141 overstates (effective n ≈ 223). The declustered pair, a 0.74 (κ 0.80, peak/trough 5) vs LFE 0.45 (p99 0.64), survives and should be the headline; 1.05 includes within-burst multiplicity (the tide modulates the number of VLFEs per burst more than burst occurrence — itself worth one sentence).

3. **(c) a = 1.05 is not a units or phase error.** Phases do not depend on stress amplitude; a time-base slip (e.g. 7 h) would offset VLFE vs LFE θ0 by ~200°, and they agree at −42° (S5 LFEs −32°). a = 2R is the first harmonic of the phase density; a von Mises κ = 1.24 gives a 1.05 with a positive density everywhere — the 1 + a cos model is just inadequate above a ≈ 1. Quote κ or peak/trough (12 all events, 5 declustered; stress-decile ratio ~8). Size is not the driver: a 0.98 above vs 1.12 below the median Mw 3.26; cos(θ−θ0) vs Mw ρ = −0.12 — the tide changes the count, not the size, which also removes the size-threshold detection worry. MINOR: K1 "same" is uninterpretable (solar-day R 0.19 ≈ K1 R 0.10); note the exponential model predicts VLFE K1 a ≈ 0.46 (K1/M2 shear amplitude 0.39, `s5_setup/tidal_constituents_per_family.csv`), observed 0.21 ± 0.1 — a 2σ tension hidden under time of day.

4. **(d) Interpretation.** Supported: VLFEs avoid the first ~day of local LFE activity (rank 0.62) and are 2–3× more tide-sensitive than LFEs of the same families in the same ±24 h, at the same phase. Not supported as stated: if VLFE rate were a convex function of local slip (LFE) rate, the densest LFE bursts would be the most tidally concentrated (they are the least, 0.38), VLFE a would rise with burst intensity (it does not: 1.17 / 1.10 / 0.97 by ±10 min-count tercile; 0.92 for no-LFE events), and hourly VLFE count vs catalogue-wide LFE count is sub-linear (binned log-log slope 0.6). So the tide acts on VLFE occurrence beyond its action on LFE rate. The real tie between Q1 and Q2: VLFE a rises with days since local onset (0.91 / 1.11 / 1.37 for Δt < 1, 1–3, ≥ 3 d; θ0 −53° → −16°), the same path S5 found for LFEs. Reword to: "VLFEs are a late-phase, strongly tide-gated part of local slow slip; they are not a proportional (or convex) sample of LFE activity."

**One extra test (findings-page gate)**: Poisson regression of hourly VLFE counts on log hourly LFE count of the VLFE-zone families (within 20 km of each episode's VLFE centroid), M2 cos/sin, and days since local onset, with episode offsets; run the same regression on hourly LFE counts. Acceptance: the M2 amplitude for VLFEs with the LFE-rate term included stays ≥ 2× the LFE value with a cluster-bootstrap CI excluding 1 → the reworded claim goes on the page. Failure signature: the VLFE M2 amplitude collapses to (rate exponent) × LFE amplitude → VLFEs are just a sample of modulated slip; drop "more tide-sensitive". Cheaper cross-check (weaker): O1 phases (in `s5_lib.PH_CONSTS`, 0.27 of M2 amplitude, not solar-locked) — exponential scaling predicts VLFE a_O1 ≈ 0.33 (0.21 declustered) vs LFE ≈ 0.13; random p99 ≈ 0.21, so only the all-event value is testable.

**What would change my mind**: VLFE M2 amplitude falling to the LFE value once local LFE rate is in the regression, or the NW-ward single-family subset staying flat when enlarged (e.g. by adding P ≥ 0.5 LFEs to define concurrency) — that would reopen a direction-dependent anchor bias in Q1.
