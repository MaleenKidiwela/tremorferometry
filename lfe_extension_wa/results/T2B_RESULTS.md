# T2B — withheld-array-station template recovery with candidate times chosen by CONFIDENCE

Written 2026-09-30 by `scripts/t2b.py` (run directly, 227 s, 12 workers). Outputs `results/t2b/` (`pair_results.csv`, `summary.csv`, `selection_counts.csv`, `candidates.parquet`, `stacks.npz`, `bootstrap_vs_t2.txt`). Same 1003 (family, withheld XU/XG station) pairs, truth templates, ceiling and scoring as T2 (`results/merlin_tests/t2/`).

## Summary (plain language)

T2 asked: if we pretend an array station is new, can we rebuild its template for a family from the times the permanent network alone picks? T2 took the ~800 strongest matched-filter peaks per family (2 per hour) and got a weak answer outside the Olympic cluster. T2B keeps the same question but chooses the times with the confidence model (the per-repeat probability P that a candidate matches the array catalogue, own-family model, scored out-of-fold by day).

- **Choosing times by confidence roughly doubles the recovered-template match in NW and SW, and brings them to 60–80 % of the ceiling.** NW median cc 0.27 (T2) → **0.54** (P ≥ 0.3) vs ceiling 0.68; own family best-matching 25 % → **41 %**, top 3: 43 % → **69 %** (P ≥ 0.5: 71 %). SW 0.15 → **0.33** (stacked pairs), own best 3 % → **28 %**, top 3 6 % → **46 %**. Arm B 0.15 → **0.42** (stacked pairs), own best 1 % → **24 %**, top 3 2 % → **35 %**. Olympic already worked and stays at 0.85 (P ≥ 0.3; own best 67 % vs T2 69 %); P ≥ 0.5 leaves too few windows there and is worse (0.76).
- **The scrambled control (permanent stations shifted to other times of the day, ranked by the same model) stays flat**: median cc 0.14–0.15, own best ≤ 1.4 %, top 3 ≤ 4 % in every region and variant. So the gain is not the model inventing a template.
- **Where the gain comes from.** The confidence candidates are the step-1 pool (≥ 8 MAD); for 95 % of pairs this pool is SMALLER than T2's ~800 peaks, so "top-K with K = T2's number" is simply the whole pool (NW median 54 windows vs 816). Most of the gain is dropping the weak peaks: the whole pool already gives NW 0.48 / own best 39 % / top 3 67 %. Ranking by P adds a further, smaller gain over ranking the same number of candidates by raw MF strength (NW P ≥ 0.3 vs same-count by net_mad: cc 0.54 vs 0.50, own best 41 vs 38 %, top 3 69 vs 66 %; SW top 3 46 vs 42 %). Candidate purity (own family within ± 2 s) rises from 5 % (T2, NW) to 69–78 %.
- **Cost: coverage.** Few pool candidates exist in SW and Arm B. P ≥ 0.3 leaves at least one window for 97 % of NW pairs, but only 65 % of SW and 45 % of Arm B (median 3 and 1 windows). Pairs with no window count as failures in the fractions above; the median cc is over pairs with a stack.
- Family-block bootstrap (1000×), P ≥ 0.3 minus T2 round 0, own-best: NW +0.16 [0.10, 0.21], SW +0.25 [0.17, 0.34], Arm B +0.23 [0.11, 0.34], Olympic −0.02 [−0.15, 0.13]; top 3: NW +0.27, SW +0.40, Arm B +0.33 (all intervals exclude 0), Olympic +0.02 (includes 0).

## Leakage handling

- The withheld station contributes nothing to the candidate times or to P. The step-1 matched filter, its 21 features, PNET (off-the-shelf and fine-tuned) and the step-2 attribution are all computed on the 42-station permanent roster (UW 23, PB 16, CN 2, US 1; `results/setup/stations.csv`). No XU/XG station enters any of them (famday station lists checked). So no refit was needed and none was done. The PNET fine-tune trained on build-half windows at 36 permanent stations only (`results/pnet/train/meta.parquet`: UW / PB / CN).
- P = `D2_hgb_FULL_own` from `results/confidence/candidates_confidence.parquet`. Every test-half row, data and scrambled control, is scored by a model fitted on the other 4 day-folds, so the P used for a day is out-of-fold. All candidates are test-half; truth templates are build-half stacks, so the events are disjoint.
- Residual, stated: the model's training labels on OTHER days are matches to the array catalogue, which was detected with the array (including the withheld station). This is label information about other days only; nothing from the scored day or from the station's waveforms on the scored day enters.
- Scrambled control = step-1 series c1 (a different site-roll seed from T2's control; both are shifts to other times of the day), with its own out-of-fold P; the withheld station is stacked unshifted at those times.

## Method

- Pool: the family's step-1 candidates (T1 all-templates permanent-network MF, ≥ 8 MAD) in the TEST half of the pair's window (V2008 / V2010).
- Variants: `topN` = top N by P, N = T2 round-0 candidate count for the pair (= the whole pool for 95 % of pairs; 13 % in Olympic, where the pool is large); `P05` / `P03` = every pool candidate with P ≥ 0.5 / ≥ 0.3; `mad_P05` / `mad_P03` = the same count as P05 / P03, chosen by net_mad (isolates the ranking effect of P). A per-day top-K variant was not run separately: the pool is smaller than K on almost every day, so it would equal `topN`.
- Stack and score: identical to T2 (`merlin_t2.py` rules): 20-Hz 1–8 Hz cache, [t−20, t+32] s windows, unit-max over 3 components, windows touching invalid data skipped. cc at 2–8 Hz (Butterworth-4, designed at fs = 20 Hz, the cache rate), best lag ± 2 s vs the own build-half truth template; rank of the own template among all families' truth templates at the station.
- Columns: `frac_stacked` = pairs with ≥ 1 window; `med_cc` over stacked pairs; `frac_cc07`, `own_best`, `top3`, `best_nbr3` over ALL pairs (no window = failure); `T2_*_same` / `ceil_med_cc_same` = T2 round 0 and the ceiling on the same stacked pairs; `med_purity_own` = median fraction of candidates within ± 2 s of an own-family array detection.
