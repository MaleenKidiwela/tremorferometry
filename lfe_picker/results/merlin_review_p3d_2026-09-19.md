# Merlin review of the P3D design — 2026-09-19 (essentials, verbatim where it matters)

**Verdict.** P3D is viable as a template-TRANSFER and RECALL study and as a MEASUREMENT of whether the dense network changes the discovery arithmetic; it is not yet viable as a discovery test, because its premise is wrong at the root: the ten new stations do not give "~12 sites at 38–45 km". Computed from results/p3d/station_epochs.csv vs the 130 families (hypocentral; family depths 31–42 km): the median family gains ONE site within 45 km (SYMB); sites within 45 km go from median 1 → 2, within 55 km from ~2–3 → 5. CLRS is the B926 site (25 m apart), OSQM is the B001 site (17 m) — no new geometry. GOBB, LOPEZ, TURTL, RNWY have 0–2 families within 45 km and median hypocentral distances 65–78 km — the same class as NLLB/B001/B004 that P3 §5.4 showed DILUTE. The single decision that matters: measure single-event registration at SYMB (and BUCKS) on known families first, convert it into a predicted pair-linkability shift with the P3 §5.5 model, and run the template-free search only if the prediction crosses. Transfer, recall and the CF re-test can run in parallel once the flaws are fixed.

## Flaws
1. FATAL for the discovery arithmetic: site count overstated ~4×. Isolated hidden families: bkeys 113, 119 gain nothing new within 55 km except GOBB; 15, 87 nothing within 45 km; only 12, 29, 62 (marginally 10) gain a genuinely new near site. Uniform-window pair-linkability will fail by 10²–10³ unless SYMB's per-event registration is ≥3× PGC's. Prior 15–20 %.
2. FATAL for the truth definition: the families SYMB can help most have the least truth. Pooled hp events 2023–26 for isolated hidden: bkey 8: 44, 10: 301, 12: 19, 15: 81, 29: 10, 62: 4, 87: 128, 113: 1, 115: 51, 119: 38. SYMB-adjacent (29, 62) have 10 and 4. "≥5/10" is unreachable by construction (≤6 isolated families have ≥20 hp truth events).
3. MAJOR: co-located pairs must be merged into sites (CLRS→B926 site, OSQM→B001 site) or the E5 site-coherent FA recurs; c_common.SITES merges only PGC/LRIV clusters; p_common.S15 and cache_index hard-code the roster (new stations silently skipped). Withhold by whole site.
4. MAJOR: hp truth carries burst features — harmless for a pairwise chain that ignores time; a leak if any arm uses temporal seeding. Pre-register a sensitivity refit without the burst block.
5. MAJOR: the frozen weight rule is N-dependent (stack S-SNR grows with N); transfer stacks (20–140 hp events, purity ~0.75) would be under-weighted. Fix: N-matched weights (below).
6. MAJOR: frozen borehole templates are NOT rotated; new stations are ZNE — rotate before any identity comparison.
7. MINOR: ODUC starts 2024-05-15 on disk (not 2023-03); gate every station-day on coverage_frac.
8. MINOR: new stations lack a5 station corrections → ±1.5 s constant-offset search charged identically to the nulls.

## Q1 Transfer protocol
Stack hp (p_real ≥ 0.8) on SSE-window days, family from the frozen cross-family assignment; N ≥ 30 per (family, station); fallback cat_core p_real ≥ 0.5 to N ≥ 60 labelled `fallback`; else `insufficient`. PGC-dominance control: split hp set at the median PGC-site z, build the new-station stack from each half; accept pooled only if both halves pass the existence nulls and correlate ≥ the new station's cross-family p95 (0.5 until computed). Stacking: e5r_templates cut_windows + align_stack (rms-normalised, 2 iterations, ±1.5 s); placement Crosson S, zero correction, ±20 s window; S pick on the aligned stack; 12-s template from S−2 s in the frozen npz format. Acceptance per (family, station) — existence, not identity, alignment-free, every freedom charged to the null: (a) S-window excess (S−1..S+5 / S−12..S−6) of the UNALIGNED stack with ±1.5 s offset search vs 200 matched random-time stacks: > p99 and ≥ +3 dB; (b) same excess at 100 wrong cells (predicted S differing ≥5 s): true > shuffled p95; (c) matched-N SAME-EVENTS control at an existing template station (nearest of PGC/VGZ/B926): if the control fails → UNTESTABLE not FAIL; (d) self-consistency: re-stack at the template's own placement correlates ≥ 0.7 with the template. Machinery positive controls FIRST: CLRS vs the B926 2012 template and OSQM vs B001 (same site) must match after rotation (cc ≥ B926 0.348 / B001 0.219 cross-family p95) for ≥70 % of control-OK families; else the machinery is broken → stop. Weights: w_new = w_ref × 10^((S-SNR_new − S-SNR_ref)/20) with both S-SNRs on the SAME events at the SAME N (subsample the reference stack; snr_N{k} columns exist), then the frozen 3×-median clip. Selection bias: not a template-validity problem; a mixture problem (56 % of families have a neighbour <2.5 km that PGC cannot separate — detect via half-split cc and sub-stack clustering at SYMB); the recall gain is real only via Q2's withheld-site certification of MARGINAL detections.

## Q2 Honest recall metric (pre-register (iii) as prediction, (i) as measurement; (ii) diagnostic only)
(iii) Fit S-SNR vs hypocentral distance per station class from e5r_template_qc_2012.csv; predict S-SNR and weight for every (family, new station); push through e5_prediction_model.py → predicted per-family recall gain at matched FA; write and hash BEFORE any transfer stack is opened. (i) Re-run both networks on the same months with the same withheld SITE set excluded from both; tiers per network by the FA-only rule on P3D quiet months; marginal = dense detections unmatched by old (±2 s one-to-one), and the reverse; certify each family's marginal set by the a3b stack test at the withheld sites (excess = 10 log10(1 + p²N(a/σ)²), calibrated on the family's own hp control); certified gain = Σ p_f N_marginal − Σ p'_f N_reverse over Σ N_hp,old, per family vs Δ(sites ≤45 km). Bar: certified gain ≥ +25 % pooled over families with ≥1 new site ≤45 km, bootstrap lower bound > 0, AND Spearman(gain, Δsites) > 0.3. Uniform gain regardless of geometry, or > 2× predicted, = the E5 site-noise signature → suspect the tier derivation. (ii) Injection ratios between networks are NOT honest (anchor mis-calibration is station-dependent; an injected stack correlates near-perfectly anywhere) — no bar.

## Q3 Discovery test
Candidates: uniform 12-s windows, hop 6 s, PNSN tremor hours within 50 km, pooled test episodes S14+S18+S21+S22 (one per-episode readout: S18). Site sum restricted a priori to sites with median hypocentral distance ≤60 km (drops NLLB, B004, B001/OSQM, GOBB, LOPEZ, TURTL, RNWY — geometry rule); all-sites and per-site-weighted as ablations. Multiple comparisons: ~3.4×10¹⁰ pairs → threshold = null quantile giving ≤30 expected false edges (≈1e-9), pre-registered. Truth T1 = hp events of the 30 hidden families (primary); T2 = sealed oracle run of the hidden families' transferred templates with withheld sites excluded (secondary); hidden families removed from the production bank (verify keys). Scorer: recall of T1 ≥ 0.5× the oracle template's own recall of T1; centroid ≤5 km; kept-explained ≤50 %; purity replaced by identity (cluster PGC stack cc > 0.524 to the 2012 PGC template AND Gate 1 pass at ≥1 withheld site). Scoreable = hidden families with ≥20 T1 events; bar on the scoreable isolated stratum (≤6): PROCEED if ≥2/3 rediscovered; unscoreable reported by name with Δsites. Nulls: N-shift (index×1,800 s, 5 seeds, 27-s overlap exclusion), N-quiet, N-moveout; claim rule unchanged. Chain: kNN → components → align_stack → S excess ≥+3 dB at ≥3 sites → g_locate 2-D → 12-s templates → o_run_month with discovered bank, withheld sites dropped → Gates 0–3 (Gate 3 testable, span >61 d) → scorer. PRIOR ≤10 % for the pairwise chain (needs δ ≈ 1.8–2.5σ vs 0.38σ → ρ_SYMB ≈ 3–4× ρ_PGC; proximity alone ≲2×). Arm B (seed-and-grow from loud windows, iterative matched filter + re-stack — Bostock's construction) prior ~25 %; pre-register separately after the pairwise prediction.

## Q4 Repeated mistakes / leaks
Time split: stations alive before 2023 calibrate on S01–S13, test on S14–S22; BUCKS/TURTL/ODUC build on S18, test on S21/S22 only. Burst-truth sensitivity. Matched network-wide FA everywhere. Co-located merge. "Episode where pairs first cross" is a forking path → one pooled set + one per-episode readout, pre-registered. No sealed referee in 2019–26: the test episodes are consumed by the first recall look and the first discovery look; 2013 stays sealed.

## Prescription (ordered)
- Step 0 roster/stores/freeze (CPU ½ d): new station table file (never edit e5r_stations.csv); site map + CLRS→B926, OSQM→B001; append new stations at the end of STAS_ORDER; rebuild share_ok_matrix; cache + mm store for new stations via an override of p_common.cache_index. Hash: hidden families, withheld site set = {B926+CLRS site, GOBB, LOPEZ, TURTL} (far sites never in any sum, doubling as Gate-1 confirmers; VGZ stays), episode split, the Q2(iii) prediction table, the discovery threshold rule. Accept: every SSE station-day coverage_frac ≥0.9 or masked. FAIL: SYMB delivery <80 % of SSE days → report before continuing.
- Step 1 co-located machinery controls (CPU, hours): CLRS vs B926, OSQM vs B001; ≥70 % of control-OK families match after rotation; else stop.
- Step 2 transfer stacks on calibration episodes (CPU 1 d): all new 3-C stations + LRIV HH; report per station attempted/accepted/insufficient, median S-SNR at matched N vs reference, and the SINGLE-EVENT LOO registration ρ at each new site vs PGC/VGZ on the same events (the number everything hinges on); Gate-1 control tables for the withheld new sites. Accept to proceed: ≥30 (family, SYMB) templates. FAIL: SYMB <10 while reference legs pass → poor site; discovery arm dead on arrival.
- Step 3 pair-rate positive control + discovery PREDICTION (GPU, hours): candidates = hp events of KEPT families in calibration episodes; P3 q_pairlink2 statistic with (i) old 7 sites and (ii) dense ≤60-km set; fit δ for both; predicted δ_full = 0.38σ × (δ_dense/δ_old). Rule: proceed to Step 6 only if predicted δ_full ≥ 1.5σ (ratio ≥ 4); otherwise the prediction IS the result → Step 7.
- Step 4 CF re-test (GPU ≤1 d, parallel): 4a kill test — at every hp event read each station's frozen CF (lowhalf) peak-time residual vs Crosson S within ±5 s; median |residual| >1.5 s at more than half of the ≤60-km sites → close the arm. New stations use the CF's unknown-station embedding (verify no S15 index). 4b back-projection on dense ≤60-km sites, thresholds 6/21/100 false events/day: (a) fraction within 5 km of a known family vs uniform 35.5 % (descriptive); (b) shuffled-moveout chance-corrected recall ratio vs hp truth ≤0.2; (c) median per-event location error ≤10 km; (d) ≥3/10 isolated hidden with ≥20 matched detections within 5 km → relative scorer with nulls. Reinstatement requires (b) AND (c) AND (d). Prior 10–15 %.
- Step 5 recall/completeness re-run (GPU 2–4 d): old-13 minus withheld, dense minus withheld, dense production; tiers per network epoch (D1 2019-01..2021-03, D2 2021-04..2023-08, D3 2023-09..) by FA-only rule (≥5k quiet family-days or flagged fallback); certified gain per Q2(i) vs the Q2(iii) prediction. FAIL signature: uniform gain or >2× predicted → site-coherent noise; re-check site merge.
- Step 6 pairwise discovery on pooled test episodes — only if Step 3 licensed it. STOP if <1/3 of scoreable isolated families.
- Step 7 arm B pre-registration (write only): seeds = top 1 % dense-site incoherent S-energy windows on tremor hours; matched-filter across pooled episodes; hits above the 1e-4 site-sum quantile; stack; iterate twice; accept clusters whose third-iteration stack passes Gate 1 at ≥2 withheld sites and count > N-shift max + 3; kill test on kept families first.
- Step 8 write-up incl. the premise correction (site table per family), ρ/δ tables, CF verdict, certified gain vs prediction, discovery verdict or prediction; referee ledger notes the test episodes as spent.

## Decisive unknowns
ρ_SYMB/ρ_PGC on shared hp events: ≥3× → pairwise arm has a real chance; 1.5–2× → recall gains 20–40 % for SYMB-adjacent families, discovery stays closed; ≤1.2× → SYMB is not the prize (check its noise PSD). CF timing residual ≤0.75 s → 5 km plausible; ≥1.5 s → closed. Certified gain concentrated on Δsites → real; uniform → FA artefact.
